# lib

Utilidades transversales y clientes de servicios externos.

- `env.ts`: validación de variables de entorno con Zod, bajo demanda.
- `supabase/`: cliente de navegador (`client.ts`), cliente de servidor (`server.ts`) y tipos de base de datos escritos a mano (`database.types.ts`). Solo usan la clave publicable.

Ver [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md).
